# Use a per-user Classic Verb for Windows File Manager Integration

Upit targets Windows 11 x64 File Manager Integration through one per-user static verb under `HKCU\Software\Classes`, shown by File Explorer under **Show more options**, and launches the private one-shot helper for exactly one selected regular file. This supersedes ADR 0015: the accepted secondary-menu placement removes package identity, sparse MSIX, `IExplorerCommand`, and trusted signing as integration prerequisites; unsigned installation is supported, while Authenticode signing remains optional for protected releases.

Windows clean success copies the Final URL, closes progress, and exits silently without attempting Toast delivery, superseding only the Windows portion of ADR 0020; macOS native notification behavior remains unchanged. Upit Desktop retains explicit inspection and Repair, installation remains current-user and transactional, and updates stage and verify the Classic Verb before removing the obsolete package/COM route. A brief dual-route overlap is allowed only inside that uncommitted transaction; success commits one Classic Verb, while failure compensates back to the previously observed route and retains recovery payload.

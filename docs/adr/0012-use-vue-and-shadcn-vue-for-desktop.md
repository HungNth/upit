# Use Vue and shadcn-vue for the desktop frontend

Upit v0.5 uses the official Wails 3 Vue template with Vue 3, TypeScript, and Vite, and owns the selected shadcn-vue component source in the repository. shadcn-vue provides accessible Reka UI primitives and consistent form controls without adding a custom component framework; no router, global state library, or external form framework is added unless the implemented interface proves one necessary.

# Release one versioned Upit product

After the separately sequenced v0.5–v0.7 work, Desktop and File Manager Integration release atomically under one Upit product version. macOS and Windows retain platform-specific packages, private helpers, signing, and native smoke gates, but users install one notarized Upit app from a DMG on macOS or one signed Upit installer/package on Windows; components do not have independent user-facing versions or installers.
